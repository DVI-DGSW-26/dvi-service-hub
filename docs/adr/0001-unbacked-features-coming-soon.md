# ADR 0001. API 가 없는 화면은 예시 값 대신 '준비 중' 으로 둔다

- 상태: 채택
- 날짜: 2026-11-16
- 관련: 포털 대시보드 API 명세 v0.5 (service-hub-server)

## 맥락

허브 화면을 새로 만들면서 디자인 단계의 예시 데이터(목업)로 먼저 화면을 그렸다. 그 뒤 서버 API 를
붙였는데, 서버가 주는 것은 명세 v0.5 의 다섯 가지(전사 공지 · 시스템 점검 · 오늘의 일정 · 회사
캘린더 · 사내 주요 소식)와 기존 `/api/auth/me` 뿐이다.

API 가 없는 자리에는 예시 값이 그대로 남아 있었다. 설정 화면의 "로그인한 기기"에는 실제로 없는
iPhone · macOS 기기가, "로그인 수단"에는 등록하지 않은 OTP · 패스키가 진짜처럼 보였다. 계정 보안
정보를 지어내 보여주는 것은 직원에게 잘못된 판단(모르는 기기가 있다고 놀라거나, OTP 를 등록했다고
믿는 것)을 하게 만든다.

## 결정

1. **데이터를 줄 API 가 없는 자리는 '준비 중' 으로 둔다.** 예시 값을 운영 화면에 내보내지 않는다.
   공용 부품 `src/shared/ui/ComingSoon.tsx` 를 쓰고, 패널 제목 옆에는 '준비 중' 배지를 단다.
2. **할 수 있는 일이 있으면 그 길은 남긴다.** 로그인 수단은 목록을 보여주지 못해도 비밀번호 변경 · OTP 등록 ·
   패스키 등록은 Keycloak 의 Application Initiated Action(`kc_action`)으로 지금도 된다. 그 버튼은 둔다.
   `pnpm dev:mock` 에서는 목록까지 가짜 데이터로 나온다.
3. **목업 코드와 타입은 지운다.** 남겨 두면 다시 화면에 섞여 들어간다. 필요하면 git 기록에서 꺼낸다.
4. **사실인 값과 아직 모르는 값을 나눈다.** 부서는 재직자(realm `employee`)인지 아닌지는 토큰으로
   알 수 있어 '미지정' 안내는 그대로 두고, 부서 이름만 '준비 중' 으로 둔다.

## 대상

| 자리 | 지금 | 막힌 이유 | 풀리는 조건 |
| --- | --- | --- | --- |
| 설정 › 로그인 수단의 **목록** | 목록만 비우고 안내 한 줄. 변경 · 등록 버튼은 동작한다(kc_action). 삭제는 credential id 가 있어야 해서 목록이 생기면 나온다 | 허브에서 읽을 API 가 없다 | 허브 서버의 `GET /account/credentials` (docs/bd.md 3.1) |
| 설정 › 로그인한 기기 | 준비 중 | 위와 같다. Keycloak 계정 콘솔도 로그인 수단 화면 하나로 줄여 두어 기기 화면으로 보낼 곳이 없다 | Keycloak 세션 API(`/account/sessions`) 연동 |
| 설정 › 내 정보의 부서 | 재직자면 준비 중, 아니면 미지정 | 토큰에 부서 클레임이 없어 `/api/auth/me` 가 주지 않는다 | Keycloak `service-hub` 클라이언트에 부서 mapper 추가 → `api/auth/callback.ts` 가 세션에 담고 `/api/auth/me` 로 내려준다 (화면은 이미 `me.department` 를 읽는다) |
| 상단 알림 | 숨김 | 알림 API 가 없다 | 알림 API |

'준비 중' 대상이 아닌 것:

- **조직도 · 빠른 링크** — 서버 API 는 없지만 예시가 아니라 실제 내용을 화면에 둔 고정 데이터다
  (`src/features/info/lib/orgChart.ts`, `src/features/quick-links/lib/quickLinks.ts`). 조직이나 링크가 바뀌면 그 파일을 고친다.
- **로컬 개발의 `mockMe`** (`src/mocks/info.ts`) — vite 에는 `/api/auth/*` 함수가 없어 개발 화면에서만
  쓴다. 운영 번들에서는 쓰지 않는다.

## 결과

- 운영 화면에 지어낸 계정 보안 정보가 나오지 않는다.
- 설정 화면이 비어 보인다. 대신 무엇이 아직 안 되는지가 화면에 드러나 우선순위를 정하기 쉽다.
- API 가 생기면 그 자리의 `ComingSoon` 을 실제 목록으로 바꾸고 이 문서의 표에서 지운다.
  표가 비면 이 ADR 은 '완료' 로 바꾼다.

## 검토한 다른 길

- **예시 값을 두고 '예시' 표시만 단다** — 계정 보안 정보는 표시가 있어도 진짜로 읽히기 쉽다. 버렸다.
- **패널을 통째로 숨긴다** — 화면은 깔끔하지만 기능이 생길 자리와 통합 로그인 링크까지 사라진다.
  알림처럼 들어갈 자리 자체가 없는 것만 숨긴다.
